How to play

Each star has a required degree — the number of selected edges touching it.

  • Anchor stars need exactly 2 selected edges.
  • Relay stars need exactly 1.
  • Dim stars need 0.

A star's outline turns green when its degree matches and pink when it doesn't. Click an edge to toggle it. Drag to pan, scroll to zoom.

Each puzzle has a unique solution — no guessing required.
